# 内容分析报告

## 文档概述

- **主题**：人人猎 - 以候选人为中心的区块链动态信用资产平台
- **类型**：融资路演PPT（A轮）
- **核心论点**：招聘行业存在信任赤字，人人猎通过信任协议和TrustScore体系解决信任量化、隐私保护和激励重塑问题

## 关键内容提取

### 1. 市场痛点（第2页）
- **高端人才不参与**：被动求职者（年薪50万+）拒绝公开简历，占比65%
- **信任无法传递**：推荐者背书无法量化，劣质驱逐优质
- **数据无法复用**：每次求职重新证明自己，体验差
- **利益分配不公**：平台/猎头/候选人三方博弈，零和游戏
- **数据支撑**：市场规模2,800亿元/年，传统猎头费率20-30%，候选人满意度仅32%

### 2. 解决方案（第3页）
- **产品定位**：信任协议（Trust Protocol），而非信息中介
- **候选人价值**：链上职业信用资产（CCA），默认隐身，3D简历，数据可携带
- **推荐官价值**：链上声誉资产（TrustScore），四层数据量化，智能合约自动分账（70%归推荐者）
- **企业价值**：精准匹配，面试结果链上存证，成本降低（费率15-20%）

### 3. 技术成熟度（第4页）
- **AI匹配**：关键词60% → LLM语义85%+（质变）
- **隐私保护**：DID+单向阀门，第一次实现隐身+触达
- **智能合约**：合规框架明确，可执行
- **社交图谱**：图计算成熟，可算圈层相似度
- **时间窗口**：18-24个月（大厂入局前建立护城河）

### 4. 三大护城河（第5页）
- **护城河1**：正向自驱飞轮（高端候选人参与 → 企业效果好 → 付费意愿提高 → 推荐官收入提高 → 更多推荐官加入）
- **护城河2**：三维数据资产（1D硬履历 → 2D熟人背调 → 3D TrustScore），需要3-5年追赶
- **护城河3**：信任网络锁定效应（TrustScore = 推荐官社会资本，离开平台 = 丢失历史积累）

### 5. 商业模式（第6页）
- **收入来源**：推荐服务费15-20%（平台抽15%，推荐官70%，候选人15%）、企业增值服务、数据服务、SaaS工具
- **第3年收入**：7,100万
- **成本结构**：人力60%、云服务15%、市场推广15%、合规10%
- **净利润率**：25-30%，约1,800-2,100万

### 6. 冷启动策略（第7页）
- **种子推荐官**：50-100人（腾讯/字节/阿里离职圈层）
- **种子企业**：10-15家（互联网/金融/医疗）
- **种子候选人**：200人（推荐官邀请+被动人才挖掘）
- **里程碑**：1月MVP，2月首批推荐关系，3月首批成单上链，6月PMF验证（月成单≥50）
- **预算**：80-95万

### 7. 竞争分析（第8页）
- **直接竞品**：猎萌、猎上网、友才网（无隐私保护、无链上信用、技术壁垒低）
- **间接竞品**：Boss直聘、猎聘（无法触达被动人才、高端市场乏力、猎头费用高）
- **最大威胁**：字节跳动（18-24个月）、腾讯（24-36个月）、阿里/蚂蚁（36个月+）
- **防御策略**：速度优先、建立圈层护城河、专注信任关系

### 8. 核心数据指标（第9页）
- **北极星指标**：月成单数（MVP≥50，成长≥300，规模≥1,000）
- **其他指标**：链上候选人入驻数、链上成单率、推荐官链上声誉覆盖率、RRP质押率、推荐官月活率
- **单位经济模型**：LTV/CAC = 6.72（健康，>3即为优秀）

### 9. 产品路线图（第10页）
- **Phase 1 MVP期**（0-6月）：验证PMF，月成单≥50，预算80-95万
- **Phase 2 成长期**（6-18月）：建立三维数据资产护城河，月成单≥300，预算542万（A轮）
- **Phase 3 规模期**（18-36月）：形成去中心化职业信用生态，月成单≥1,000，预算2,000万（B轮）
- **Phase 4 生态期**（36月+）：成为全球领先的职业信用基础设施

### 10. 团队配置（第11页）
- **MVP期团队**：5-6人（CTO创始人兼任、后端2人、前端1人、AI1人兼职、运维外包）
- **成本**：约122,500/月
- **6个月预算**：80-95万

### 11. 风险分析（第12页）
- **市场风险**：冷启动失败（中概率高影响）、大厂入局（高概率高影响）
- **技术风险**：区块链性能瓶颈、智能合约漏洞
- **合规风险**：区块链监管收紧、积分合规
- **财务风险**：现金流断裂
- **应对策略**：精准种子用户策略、速度优先、链下计算+链上存证、等保2.0认证

### 12. 融资计划（第13页）
- **融资轮次**：A轮
- **融资金额**：500-800万
- **投前估值**：4,000-5,000万
- **释放股份**：10-15%
- **退出路径**：战略并购（第5-7年，10-20倍）、IPO（第7-10年，50-100倍）、分红回报（第4年起）

### 13. 核心竞争优势（第14页）
- **对比传统招聘平台**：信息中介 → 信任协议，流量差价 → 信任流转服务费，无信任机制 → TrustScore体系，一次性数据 → 三维资产，平台主导分润 → 智能合约自动分账
- **为什么现在**：AI+隐私+智能合约+社交图谱四层技术首次成熟
- **为什么是我们**：创始团队有腾讯/字节/阿里离职圈层资源、产品设计解决真问题、技术架构兼顾创新与合规
