## 内容概要
人人猎是一个以候选人为中心的区块链动态信用资产平台，旨在解决招聘行业的信任赤字问题。通过TrustScore体系和智能合约，实现信任量化、隐私保护和激励重塑。

## 核心价值
- 候选人拥有链上职业信用资产（CCA）
- 推荐官建立链上声誉资产（TrustScore）
- 企业获得高质量被动人才
