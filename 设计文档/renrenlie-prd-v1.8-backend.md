# 人人猎管理后台 PRD 文档 v1.0

## 1. 产品概述

### 1.1 产品定位
**管理后台**是人人猎平台的核心运营支撑系统，面向平台运营人员，提供用户管理、审核管理、权益配置、数据分析等功能，确保平台的正常运营和用户体验。

### 1.2 核心价值
- 统一的运营管理入口
- 高效的用户审核流程
- 精细化的权益配置
- 全面的数据分析和监控
- 安全的系统管理

## 2. 用户角色与权限

### 2.1 系统用户角色
| 角色 | 职责 | 权限 |
|------|------|------|
| **超级管理员** | 系统最高权限 | 所有功能模块的访问和操作权限 |
| **平台运营** | 日常运营管理 | 用户管理、审核管理、内容管理 |
| **财务专员** | 财务数据管理 | 资金管理、佣金结算、财务报表 |
| **数据分析师** | 数据分析与监控 | 数据查看、报表导出、监控配置 |
| **客服专员** | 用户支持 | 工单处理、用户反馈管理 |

## 3. 功能模块规划

### 3.1 仪表盘（Dashboard）
- **核心数据指标**：
  - 平台总用户数（猎头/候选人/企业）
  - 日活跃用户数（DAU）
  - 月活跃用户数（MAU）
  - 职位发布数/推荐数/成单数
  - 佣金流水统计
  - 纠纷率统计
- **实时数据展示**：
  - 最近24小时活跃用户趋势
  - 最近7天职位发布趋势
  - 最近30天成单金额趋势
  - 各区域用户分布地图
- **重要提醒**：
  - 待审核用户列表
  - 待处理工单
  - 系统异常报警

### 3.2 用户管理

#### 3.2.1 推荐人管理
- 用户列表展示（OneID、姓名、手机、邮箱、TrustScore、等级、注册时间）
- 搜索与筛选功能
- 用户详情查看：
  - 基础信息（身份认证、联系方式）
  - TrustScore历史记录
  - 推荐历史
  - 佣金收入
  - 违规记录
- 操作功能：
  - 冻结/解冻用户
  - 修改用户等级
  - 发送消息
  - 查看登录日志

#### 3.2.2 候选人管理
- 用户列表展示（OneID、姓名、手机、邮箱、信用评分、简历完整性、注册时间）
- 搜索与筛选功能
- 用户详情查看：
  - 基础信息（身份认证、联系方式）
  - 简历信息（教育/工作经历/技能）
  - 信用档案（CCA）
  - 面试/入职记录
- 操作功能：
  - 冻结/解冻用户
  - 发送消息
  - 查看登录日志

#### 3.2.3 企业管理
- 用户列表展示（OneID、企业名称、行业、规模、注册时间、认证状态）
- 搜索与筛选功能
- 用户详情查看：
  - 基础信息（企业资质、联系人）
  - 职位发布记录
  - 候选人筛选记录
  - 佣金支付记录
- 操作功能：
  - 冻结/解冻用户
  - 发送消息
  - 查看登录日志

### 3.3 审核管理

#### 3.3.1 身份认证审核
- 待审核用户列表（推荐人/候选人/企业）
- 审核详情：
  - 身份信息验证（姓名、身份证号、照片）
  - 资质证明（猎头从业证明、企业营业执照）
  - 人脸识别比对
- 操作功能：
  - 审核通过/拒绝
  - 备注审核意见
  - 批量处理

#### 3.3.2 职位发布审核
- 待审核职位列表
- 审核详情：
  - 职位信息（标题、公司、薪酬、要求）
  - 企业资质验证
  - 职位真实性评估
- 操作功能：
  - 审核通过/拒绝
  - 备注审核意见
  - 批量处理

#### 3.3.3 内容审核
- 用户发布内容审核（评论、动态、简历）
- 审核详情：
  - 内容预览
  - 违规关键词检测
  - 敏感信息识别
- 操作功能：
  - 审核通过/拒绝
  - 屏蔽内容
  - 发送警告

### 3.4 权益配置

#### 3.4.1 推荐人权益配置
- 等级配置（S/A/B/C/D级）
- 权限配置（每日推荐次数、职位查看权限、佣金比例）
- 认证配置（垂直领域认证条件、出海岗位服务资格）
- 激励配置（推荐奖励、入职补贴、等级提升条件）

#### 3.4.2 企业权益配置
- 套餐配置（基础版/专业版/企业版）
- 权限配置（职位发布数量、候选人查看权限、数据分析权限）
- 价格配置（平台费率、增值服务价格）
- 优惠配置（新用户优惠、批量招聘折扣）

#### 3.4.3 候选人权益配置
- 简历可见性配置（公开/半公开/隐身模式）
- 授权配置（单次授权时间、企业查看权限）
- 补贴配置（入职补贴比例、解冻条件）
- 隐私配置（数据导出权限、删除账户规则）

### 3.5 资金管理

#### 3.5.1 佣金结算
- 待结算佣金列表
- 佣金详情查看：
  - 推荐人信息
  - 候选人信息
  - 职位信息
  - 佣金金额
  - 结算状态
- 操作功能：
  - 手动结算
  - 批量结算
  - 退款处理

#### 3.5.2 资金流水
- 资金流水记录（收入/支出）
- 搜索与筛选功能（时间范围、类型、金额范围）
- 导出功能（Excel/CSV）

#### 3.5.3 退款管理
- 退款申请列表
- 退款详情查看
- 操作功能：
  - 同意/拒绝退款
  - 备注处理意见

### 3.6 数据分析

#### 3.6.1 用户分析
- 用户增长趋势（新增用户数/活跃用户数/留存率）
- 用户分布（地区/行业/职位/学历）
- 用户行为分析（登录频率/使用时长/功能使用）
- 用户流失分析（流失原因/挽回策略）

#### 3.6.2 招聘数据分析
- 职位发布/查看/申请统计
- 推荐成功率分析（推荐数/面试数/入职数）
- 职位匹配度分析（JD契合度/候选人匹配度）
- 招聘周期分析（各阶段时间分布）

#### 3.6.3 财务分析
- 佣金收入统计（每日/每周/每月）
- 支出统计（补贴/奖励/退款）
- 平台营收分析（总收入/净收入/利润率）
- ROI分析（投资回报率）

#### 3.6.4 系统数据分析
- 系统访问量统计（PV/UV）
- 功能使用频率统计
- 系统性能监控（响应时间/错误率）
- 安全事件记录

### 3.7 内容管理

#### 3.7.1 首页轮播图
- 轮播图列表管理
- 操作功能：
  - 添加/编辑/删除轮播图
  - 设置轮播顺序
  - 启用/禁用轮播图
  - 预览效果

#### 3.7.2 通知公告
- 通知公告列表管理
- 操作功能：
  - 发布新通知
  - 编辑/删除通知
  - 设置通知优先级
  - 查看通知阅读情况

#### 3.7.3 帮助中心
- 帮助文档管理
- 常见问题管理
- 操作功能：
  - 添加/编辑/删除帮助内容
  - 分类管理
  - 搜索功能

### 3.8 系统管理

#### 3.8.1 角色与权限管理
- 系统角色管理
- 权限配置（功能模块访问权限、操作权限）
- 操作功能：
  - 添加/编辑/删除角色
  - 分配权限
  - 角色用户管理

#### 3.8.2 系统配置
- 基础配置（平台名称、域名、联系方式）
- 邮件配置（SMTP服务器、发送邮箱）
- 短信配置（短信服务商、API密钥）
- 支付配置（支付接口、商户信息）

#### 3.8.3 日志管理
- 系统操作日志（用户操作记录）
- 系统访问日志（用户登录记录）
- 系统错误日志（异常情况记录）
- 搜索与筛选功能

## 4. 技术架构

### 4.1 前端技术栈
- React 18 + TypeScript
- 后台管理框架（Ant Design Pro/Vite Admin）
- 图表库（ECharts/AntV）
- 权限管理（React Router + Casbin）

### 4.2 后端技术栈
- Node.js + Express/Koa
- 数据库（MongoDB/MySQL/Redis）
- 身份认证（JWT/SSO）
- 消息队列（Redis/RabbitMQ）

### 4.3 安全架构
- 数据加密（敏感数据加密存储）
- 接口安全（API签名、请求频率限制）
- 权限控制（基于角色的访问控制）
- 审计日志（操作记录追踪）

## 5. 界面设计规范

### 5.1 设计风格
- 简洁现代的界面设计
- 统一的配色方案（蓝色系为主）
- 清晰的信息层级
- 响应式设计，适配不同屏幕尺寸

### 5.2 布局结构
- 左侧导航栏（功能模块）
- 顶部工具栏（用户信息、通知、搜索）
- 主体内容区域（模块内容展示）
- 底部状态栏（系统信息、帮助）

## 7. 风险评估与应对

### 7.1 数据安全风险
- **风险**：用户敏感数据泄露
- **应对**：数据加密存储、API接口安全、权限控制

### 7.2 系统性能风险
- **风险**：高并发下系统响应慢
- **应对**：代码优化、数据库优化、缓存策略

### 7.3 操作失误风险
- **风险**：管理员误操作导致数据损失
- **应对**：操作日志记录、数据备份、操作确认机制

## 8. 验收标准

### 8.1 功能验收
- 所有功能模块按PRD文档实现
- 交互流畅，无明显bug
- 数据展示准确

### 8.2 性能验收
- 页面加载时间<2秒
- 系统响应时间<500ms
- 支持1000+用户并发访问

### 8.3 安全验收
- 敏感数据加密存储
- 接口安全认证
- 权限控制完善
