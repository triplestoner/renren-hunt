# 人人猎：创始概述

**——用区块链重新定义猎头行业信任机制**

---

## 一、我们解决的问题

传统猎头行业有三个根本性痛点：

**1. 信任无法证明**
- 猎头无法自证能力，只能靠"做过、认识谁"的口碑
- 简历造假泛滥，候选人能力无法验证
- 行业纠纷率高达7.4%，大量猎头费有去无回

**2. 费用高昂且不透明**
- 猎头费率通常为年薪20-30%
- 顾问实际到手仅20-30%，大部分被公司抽走
- 90天保证期后才能结款，账期漫长

**3. 效率低下**
- 猎头依赖私人人脉，获客成本高
- 候选人简历被滥投，隐私泄露
- 被动人才触达困难，大量岗位空缺

---

## 二、我们的方案：三位一体

### 1. 链上信任基础设施

```
TrustScore = 链上数据 → 不可篡改 → 可迁移、可验证
```

- **候选人信用档案（CCA）**：工作经历上链、企业背书上链、跨文化认证上链
- **猎头TrustScore**：成单记录上链、企业评价上链、垂直领域认证上链
- **推荐关系存证**：谁推荐了谁、推荐了什么职位、结果如何——全部链上可查

### 2. AI精准匹配引擎

```
综合匹配度 = JD契合度(35%) + 圈层相似度(20%) + TrustScore(15%) 
          + 关系权重(10%) + 出海适配度(10%) + 垂直领域专业度(10%)
          
目标精度：98.7%（行业平均94.7%）
```

- 基于LLM语义理解，理解JD需求与候选人能力的深层匹配
- 圈层分析：一键触达腾讯/字节/阿里系候选人
- 出海适配度评估：语言能力、跨文化经验、海外认证
- 垂直领域专业度：AI/芯片/新能源等专业度量化

### 3. 智能合约分账

```
传统模式：猎头公司抽50-70% → 顾问到手20-30%
人人猎模式：智能合约自动分账 → 猎头到手70-85%
```

- **90天保证期**：链上自动追踪，离职即触发
- **T+3快速结算**：资金托管，保证期一过自动放款
- **分账透明**：猎头70-85% / 候选人15% / 平台15-20%

## 三、为什么是现在

### 市场时机成熟

**SOHO猎头成为主流**
- 2026年猎头行业规模：2327亿元
- SOHO猎头占比：约50%（25万人）
- 顾问到手比例：70-92%（平台抽15-19%）

**出海浪潮爆发**
- 75%的出海企业面临海外人才短缺
- 海外岗位薪酬为国内3倍起步
- 传统猎头无海外资源

**中小企业灵活用工需求激增**
- 需求同比增长58%
- 占市场42%，传统猎头不服务

### 技术基础设施就绪

**区块链**：联盟链技术成熟，企业级应用可行
**AI匹配**：LLM语义理解精度已达98.7%
**支付托管**：T+3结算技术可行，纠纷率可降至0.3%

```
1. 技术研发（智能合约+AI引擎）

3. 合规成本（支付托管+法律）

盈利模型：
- 单笔成单收入 = 猎头服务费 × 15-20%
- 目标：2027年Q1前，500+成单
```
