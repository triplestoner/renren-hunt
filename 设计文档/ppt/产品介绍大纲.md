# 人人猎产品介绍

## 一、项目缘起

### 1.1 客户访谈体感

**高端人才招聘需求旺盛**
- 顶级研发人才和高管岗位基本通过猎头招聘
- 每年预算百万级
- 高端人才一般不会主动投简历

**猎头业务痛点**
- 不是签单，而是交付
- 能够及时给反馈、交付合适的人才
- 人才库匮乏、人才不活跃、处理效率不高

---

## 二、人人猎模式创新

### 2.1 产品愿景

**让人才流动真正实现数字化、资产化与无缝化**
- 通过技术的确定性解决商业环境中的不信任
- 让信任在链上自由流转

**人人猎 = 中高端人才招聘的信任协议（Trust Protocol）**

### 2.2 战略定位

| 维度 | 描述 |
|------|------|
| 产品类型 | C2C2B 熟人社交推荐 × 去中心化招聘 × 信任协议 |
| 目标用户 | 候选人(核心资产所有者)、推荐官、企业HR(需求方) |
| 核心价值主张 | 信任数字化流转 × 智能合约分账 × AI精准匹配 × 零沉没成本 × 链上信用资产 |
| 对标参考 | LinkedIn职业档案 + Wanted推荐体验 + 区块链信用资产逻辑 + 传统猎头商业模式 |
| 差异化壁垒 | 独家三维数据资产 + 沉睡高端隐私人才池 + 不可迁移的网状信用网络 |

---

## 三、传统模式之困

### 六大结构性缺陷

| 缺陷维度 | 具体问题 | 后果 |
|----------|---------|------|
| 组织模式 | 单向树状扩散，信息由上至下流转 | 层级摩擦高，效率随层级递减 |
| 技术漏洞 | 简历可私转、飞单 | 不可追溯，猎企利益受损 |
| 数据孤岛 | 候选人资源沉淀在猎头私域 | 无法共享形成合规模化 |
| 隐私安全 | 候选人被动曝光 | 高端人才抗拒陌生联系 |
| 利益分配 | 平台/老板吃大头 | 推荐者动力不足 |
| 企业成本 | 年薪20-30% | 高额预付沉没成本 |

---

## 四、人人猎的降维打击

| 对比维度 | 传统猎头机构 | 人人猎 |
|----------|-------------|--------|
| 组织架构 | 单向树状扩散，高摩擦 | 网状裂变C2C2B，指数级扩散 |
| 数据确权防作弊 | 极易泄露、飞单频发、不可追溯 | 区块链数字水印，全链路可追溯 |
| 隐私保护 | 被动曝光，高端人才抗拒拒绝 | DID简历主权，候选人主动授权解锁 |
| 交付周期 | 2-3个月，纯人工盲搜 | AI引擎秒级筛选，熟人背书极速触达 |
| 利益分配 | 平台/老板吃大头，推荐者付出与收获不匹配 | 智能合约自动分账，两端获利最大化 |
| 企业成本 | 年薪20-30%，高额预付沉没成本 | 降至月薪比例，无沉没成本 |

## 五、核心产品功能

### 5.1 链上信任基础设施

- **CCA信用档案**：候选人信用档案上链
- **TrustScore**：猎头信用评分不可篡改
- **推荐关系存证**：全链路可追溯

### 5.2 AI精准匹配引擎

- **综合匹配度98.7%**
- 六维度智能推荐
- 出海适配度评估

### 5.3 智能合约分账

- **T+3快速结算**
- **猎头到手70-85%**
- 资金托管保障
