# 竞品开源项目调研报告

> 日期：2026-04-12
> 目的：为「人人猎」项目寻找可参考和借鉴的开源实现

---

## 一、调研概述

本报告针对「人人猎」招聘赏金平台，调研 GitHub 上类似的开源项目。「人人猎」的核心商业模式如下：

- **赏金猎头**：推手（猎人）推荐候选人获得赏金
- **资金托管**：B端企业支付托管金，保证期内按天折算退款
- **AI匹配**：向量匹配 + LLM 生成个性化沟通话术
- **微信小程序**：前端使用微信原生开发

## 五、总结与建议

### 5.1 优先参考

1. **人人猎头小程序（全开源）**：完整商业项目，融合社交网络与招聘网站，最直接参考
2. **Algora**：最完整的招聘赏金平台实现，涵盖 job、bounty、contract、payment 全流程
3. **RefRef**：专注于 referral 归因和奖励系统，适合深入研究推荐逻辑
4. **Resume Matcher / SmartResume**：AI 匹配与简历解析的核心参考

### 5.2 技术选型建议

- 后端语言：Algora 使用 Elixir/Phoenix，但 Python + FastAPI 方案更主流
- 数据库：与人人猎选型一致（PostgreSQL + Redis + MongoDB）
- 前端：小程序原生 vs Algora 的 Web 端，根据实际需求选择
- AI 匹配：采用 Resume Matcher 的 FastEmbed 方案进行向量匹配
- 简历解析：参考 SmartResume 的 OCR + LLM 方案

### 5.3 潜在扩展方向

- 将 GitHub App 集成改为「微信聊天记录提取简历」
- 将 Stripe 支付改为「微信支付」
- 增加「按天折算退款」的专门模块（目前开源项目较少见，可自研）
