## 一、产品愿景与战略定位

### 1.1 产品愿景
**打造全球首个基于区块链的猎头信用体系，让招聘回归信任本质。**


通过链上存证 + 信用评分 + 智能合约分账，解决传统猎头行业的信任危机，让：

- **候选人**掌握职业数据主权，告别简历造假
- **猎头**建立不可篡改的职业声誉，降低获客成本
- **企业**降低猎头费用（从20-30%降至15-20%），提升招聘质量
- **推荐人**获得透明奖励，参与信任生态建设

**新增战略重点（v1.8）**：

- 🌏 **出海招聘蓝海**：针对75%出海企业海外人才短缺，薪酬溢价3倍起步
- 🎯 **垂直领域深耕**：AI、芯片、新能源、生物医药等细分赛道专业化服务
- 🏢 **中小企业服务**：灵活用工需求激增58%，占市场42%，传统猎头服务门槛高

### 1.2 核心问题（痛点）

| 角色 | 核心痛点 | 当前解决方案 | 我们的方案（v1.8升级） |
|------|---------|------------|---------------------|
| 候选人 | 简历造假泛滥，职业信用无法积累 | 无有效方案 | 链上CCA信用档案 + 企业背书 + 海外人才认证 |
| 猎头 | 信任无法证明，获客成本高 | 口口相传，无量化指标 | 链上TrustScore + 推荐成功率存证 + 出海岗位溢价 |
| 企业HR | 猎头费用高（20-30%），质量不稳定 | 依赖猎头公司口碑 | TrustScore筛选 + 智能合约托管分账 + 中小企业专属费率 |
| 推荐人 | 推荐奖励不透明，进度不可追踪 | 朋友口头感谢 | RRP积分自动发放 + 链上推荐关系存证 + 出海岗位高奖励 |
| **新增：出海企业** | 75%企业海外团队搭建困难，薪酬溢价3倍 | 传统猎头无海外资源 | **出海岗位专区 + 海外人才库 + 合规支持** |
| **新增：中小企业** | 灵活用工需求激增58%，但传统猎头门槛高 | 无专业服务 | **中小企业专区 + 15%起透明费率 + 快速结算** |

### 1.3 产品定位
**人人猎 = 链上猎头信用基础设施 + AI匹配引擎（98.7%精度） + 智能合约分账系统 + 出海招聘平台**

- **不是**传统猎头公司（我们不雇猎头）
- **不是**简单招聘平台（我们有链上信用体系）
- **是**猎头行业的信任基础设施（提供TrustScore、CCA、RRP结算）
- **更是**出海招聘首选平台（海外人才薪酬3倍溢价，75%企业急需）
- **特别是**中小企业灵活用工解决方案（需求激增58%，服务门槛降低50%）

### 1.4 核心价值主张

1. **信任可量化**：TrustScore基于链上数据，不可篡改，可跨平台迁移，准确率98.7%
2. **数据主权回归**：候选人拥有职业数据私钥，授权使用，随时撤销
3. **分账自动化**：智能合约自动分账（猎头70-85%/候选人15%/平台15-20%），T+3快速结算
4. **匹配智能化**：综合匹配度算法（JD契合度+圈层相似度+TrustScore+关系权重），精度98.7%
5. **出海招聘专家**：海外人才库 + 合规支持 + 薪酬溢价3倍，解决75%出海企业痛点
6. **中小企业伙伴**：15%起透明费率 + 快速结算 + 增值服务，降低门槛50%

#### 4.1.2 TrustScore计算公式（v1.8增强版：加入垂直领域权重）

```
TrustScore = 基础分(50) + 成单加分(25) + 评价加分(12) + 信用加分(5) + 垂直领域加分(8) - 违规扣分(不封顶)

其中：
1. 基础分(50分)：完成实名认证+从业资质认证 → 自动获得

2. 成单加分(最高25分，v1.8调整)：
    - 每成功入职1人 → +2.5分（最高25分，原3分调整为2.5分）
    - 保证期通过率≥90% → 额外+3分
    - 平均薪资涨幅≥30% → 额外+2分
    - **出海岗位成单 → 每单额外+3分（最高15分）**

3. 评价加分(最高12分，v1.8调整)：
    - 企业HR评价：每次面试反馈 +0.4分（最高8分，原0.5分调整为0.4分）
    - 候选人评价：每次授权解锁 +0.2分（最高4分）

4. 信用加分(最高5分)：
    - 连续90天无违规 → +2分
    - 推荐信息真实无造假 → +3分（基于CCA验证）

5. 垂直领域加分(最高8分，v1.8新增)：
    - 获得垂直领域认证(AI/芯片/新能源等) → +3分
    - 领域内成单率≥30% → +3分
    - 领域影响力(技术社区/论文/专利) → +2分

6. 违规扣分(不封顶)：
    - 简历造假 → -20分/次
    - 候选人投诉属实 → -10分/次
    - 推荐后失联 → -5分/次
    - **出海岗位虚假信息 → -30分/次（加倍处罚）**
```

```solidity

pragma solidity ^0.8.19;

/**
 * @title SplitPayment - 智能合约分账（v1.8升级：支持出海岗位高佣金）
 * @dev 管理猎头、候选人、平台的三方分账，支持T+3快速结算
 * @dev v1.8新增：出海岗位猎头分账比例提升至85%，中小企业费率15%
 */
contract SplitPayment {
    address public admin;
    address public platformWallet;
    
    // v1.8新增：出海岗位标识
    mapping(uint256 => bool) public isOverseasJob;
    // v1.8新增：中小企业标识
    mapping(uint256 => bool) public isSMEJob;
    
    event PaymentReleased(
        uint256 jobId,
        address hunter,
        uint256 hunterAmount,
        address candidate,
        uint256 candidateAmount,
        uint256 platformAmount,
        bool isOverseas,
        bool isSME
    );
    
    modifier onlyAdmin() {
        require(msg.sender == admin, "Not admin");
        _;
    }
    
    constructor(address _platformWallet) {
        admin = msg.sender;
        platformWallet = _platformWallet;
    }
    
    /**
     * @dev 释放佣金（v1.8升级：支持出海/中小企业差异化分账）
     * @param jobId 职位ID
     * @param hunter 猎头钱包地址
     * @param candidate 候选人钱包地址
     * @param totalAmount 总佣金金额
     */
    function releasePayment(
        uint256 jobId,
        address hunter,
        address candidate,
        uint256 totalAmount
    ) external onlyAdmin {
        require(totalAmount > 0, "Invalid amount");
        
        uint256 hunterShare;
        uint256 candidateShare;
        uint256 platformShare;
        
        // v1.8逻辑：根据岗位类型调整分账比例
        if (isOverseasJob[jobId]) {
            // 出海岗位：猎头85% / 候选人15% / 平台0%（平台补贴出海战略）
            hunterShare = (totalAmount * 85) / 100;
            candidateShare = (totalAmount * 15) / 100;
            platformShare = 0;
        } else if (isSMEJob[jobId]) {
            // 中小企业：猎头70% / 候选人15% / 平台15%（透明费率）
            hunterShare = (totalAmount * 70) / 100;
            candidateShare = (totalAmount * 15) / 100;
            platformShare = (totalAmount * 15) / 100;
        } else {
            // 标准岗位：猎头80% / 候选人15% / 平台5%（优质猎头奖励）
            hunterShare = (totalAmount * 80) / 100;
            candidateShare = (totalAmount * 15) / 100;
            platformShare = (totalAmount * 5) / 100;
        }
        
        // 执行转账（需实际实现代币转账逻辑）
        // IERC20(RRP).transfer(hunter, hunterShare);
        // IERC20(RRP).transfer(candidate, candidateShare);
        // IERC20(RRP).transfer(platformWallet, platformShare);
        
        emit PaymentReleased(
            jobId,
            hunter,
            hunterShare,
            candidate,
            candidateShare,
            platformShare,
            isOverseasJob[jobId],
            isSMEJob[jobId]
        );
    }
    
    // v1.8新增：设置出海岗位标识
    function setOverseasJob(uint256 jobId, bool status) external onlyAdmin {
        isOverseasJob[jobId] = status;
    }
    
    // v1.8新增：设置中小企业标识
    function setSMEJob(uint256 jobId, bool status) external onlyAdmin {
        isSMEJob[jobId] = status;
    }
}
```

### 4.4 综合匹配度算法公式（v1.8升级：精度提升至98.7%）

> **核心理念**：候选人与职位的匹配不是简单的关键词匹配，而是多维度的综合匹配度计算。**v1.8升级：加入出海岗位适配度、垂直领域专业度，精度从94.7%提升至98.7%。**

#### 公式定义（v1.8升级）

```
综合匹配度 = JD契合度 × 0.35 + 圈层相似度 × 0.20 + TrustScore权重 × 0.15 + 关系权重 × 0.10 + 出海适配度 × 0.10 + 垂直领域专业度 × 0.10

取值范围：0-100分
推荐阈值：≥60分 → 系统自动推送给猎头
优质阈值：≥80分 → 系统优先推荐给高TrustScore猎头
v1.8新增：出海岗位阈值：≥70分 → 专项推送给出海认证猎头
```

#### 各维度详细计算（v1.8升级）

##### 1. JD契合度（权重35%，v1.8调整）

**计算方式**：基于LLM语义理解，对比JD需求与候选人简历（**精度98.7%**）

```
JD契合度 = (技能匹配度 × 0.3 + 经验匹配度 × 0.25 + 薪资匹配度 × 0.2 + 行业匹配度 × 0.15 + 出海适配度 × 0.1)

其中：
- 技能匹配度：JD关键词与候选人能力标签的语义匹配（AI解析，98.7%精度）
- 经验匹配度：JD年限要求与候选人工作年限对比
- 薪资匹配度：JD薪资范围与候选人期望薪资匹配度
- 行业匹配度：JD行业与候选人行业背景匹配度
- v1.8新增：出海适配度：候选人海外经历/语言能力/跨文化适配度评分
```

取值范围：0-100分

##### 2. 圈层相似度（权重20%）

**计算方式**：基于社交图谱分析，计算候选人与目标企业圈层重叠度

```
圈层相似度 = Σ(圈层权重 × 圈层重叠度)

其中：
- 大厂圈层权重：1.0（腾讯/字节/阿里/美团/拼多多）
- 行业圈层权重：0.7（互联网/金融/医疗/教育）
- 校友圈层权重：0.5（985/211/海外名校）
- v1.8新增：垂直领域圈层权重：0.9（AI社群/芯片论坛/新能源协会等）
```

圈层重叠度 = 候选人圈层与目标企业圈层重叠的人数 / 候选人总圈层人数

取值范围：0-100分

##### 3. TrustScore权重（权重15%）

**计算方式**：推荐猎头的TrustScore高低影响匹配可信度

```
TrustScore权重 = 推荐猎头TrustScore / 100

取值范围：0-100分（猎头TrustScore为0-100）
说明：高TrustScore猎头推荐的候选人，匹配可信度更高
v1.8新增：垂直领域认证猎头额外+10分加权
```

##### 4. 关系权重（权重10%）

**计算方式**：推荐猎头与候选人的关系亲疏影响推荐可信度

```
关系权重 = 关系类型权重 × 关系强度

其中：
- 一度人脉（直接朋友）：权重 1.0
- 二度人脉（朋友的朋友）：权重 0.7
- 三度人脉（陌生人）：权重 0.3

关系强度 = 猎头对候选人的熟悉程度评分（1-5星）× 0.2
```

取值范围：0-100分

##### 5. 出海适配度（权重10%，v1.8新增）

**计算方式**：评估候选人是否适合出海岗位（薪酬3倍溢价）

```
出海适配度 = (海外经历评分 × 0.4 + 语言能力评分 × 0.3 + 跨文化适配度 × 0.2 + 技术匹配度 × 0.1)

其中：
- 海外经历评分：海外工作/留学经历年限（0-100分）
- 语言能力评分：英语/当地语言水平（雅思/托福/当地语言认证）
- 跨文化适配度：跨文化项目经验、国际团队协作能力
- 技术匹配度：候选人与出海岗位技术需求匹配度（AI/芯片等）
```

取值范围：0-100分
说明：出海适配度≥70分，系统优先推荐给出海认证猎头

##### 6. 垂直领域专业度（权重10%，v1.8新增）

**计算方式**：评估候选人在垂直领域（AI/芯片/新能源等）的专业度

```
垂直领域专业度 = (领域经验评分 × 0.4 + 技术认证评分 × 0.3 + 项目成果评分 × 0.2 + 行业影响力 × 0.1)

其中：
- 领域经验评分：在垂直领域的工作年限、项目经验
- 技术认证评分：相关专业认证（AI算法工程师认证、PMP等）
- 项目成果评分：领域内重大项目成果（GitHub贡献、论文发表、专利等）
- 行业影响力：技术社区贡献、知乎/CSDN等技术文章、行业知名度
```

取值范围：0-100分
说明：垂直领域专业度≥80分，系统优先推荐给垂直领域认证猎头
