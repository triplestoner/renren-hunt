六、小程序页面交互升级
6.1 简历上传与解析交互 (解决手机端痛点)
由于手机端选取本地文件困难，MVP 提供以下三种方式：
1. 微信原生选择：调用 `wx.chooseMessageFile` 直接从微信聊天记录（如“文件传输助手”）中提取 PDF/Word 简历。
2. 文本直贴：提供一个巨大的 Textarea，推手可以直接复制简历文本内容粘贴解析。
3. （彩蛋）PC端直传：生成一个带参数的小程序码，推手扫码后在 PC 浏览器打开内嵌 H5 进行批量拖拽上传。

6.2 资金托管页
B端确认面试或发Offer时，强制弹出“资金托管”收银台：
- 显示本次岗位总赏金：￥20,000
- 保证期条款：90天内离职，按天折算（每天 20000/90 = 222.22元）
- 微信支付发起托管付款，资金进入平台监管户。

七、核心业务逻辑：按天折算退款 (代码示意)
```python
def calculate_refund(escrow_amount: float, guarantee_days: int, start_date: date, exit_date: date) -> float:
    """
    计算按天退款金额
    """
    actual_days = (exit_date - start_date).days
    if actual_days < 0:
        return escrow_amount # 未入职全退
    if actual_days >= guarantee_days:
        return 0.0 # 过保不退
        
    daily_rate = escrow_amount / guarantee_days
    earned_amount = daily_rate * actual_days
    refund_amount = escrow_amount - earned_amount
    return round(refund_amount, 2)
```
