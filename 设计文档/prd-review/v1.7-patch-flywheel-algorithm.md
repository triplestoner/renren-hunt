## 3.3 六步流转商业飞轮（从v1.4补入）

> **核心理念**：人人猎的商业闭环不是线性流程，而是六步流转的信任飞轮，每一步都在链上存证，形成不可篡改的信任流转记录。

```
┌─────────────────────────────────────────────────────────────────────┐
│                    六步流转商业飞轮                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   第一步：候选人入驻与信用初始化                                    │
│   ├── 候选人注册OneID → 完成简历填写                               │
│   ├── 选择数据授权范围 → 签署数据上链协议                         │
│   ├── 链上身份生成（候选人持有私钥）                               │
│   └── 获得3D简历框架（硬履历+熟人背调+信用评分）                   │
│           ↓                                                         │
│   第二步：猎头发现与推荐建立                                        │
│   ├── 猎头发现候选人（圈层推荐/AI匹配）                            │
│   ├── 猎头填写前置背调 → 标注候选人圈层标签                        │
│   ├── 候选人授权解锁 → 推荐关系上链存证                            │
│   └── 智能合约记录推荐ID、猎头、候选人、职位、时间戳              │
│           ↓                                                         │
│   第三步：面试流程与结果上链                                        │
│   ├── 企业安排面试 → 猎头陪同                                      │
│   ├── 面试结束后 → 企业强制填写面试反馈                            │
│   ├── 面试结果上链存证（评分+简短评价）                            │
│   └── 候选人可查看面试反馈 → 信任透明化                            │
│           ↓                                                         │
│   第四步：入职确认与薪资上链                                        │
│   ├── 候选人入职 → 企业确认入职（触发入职确认合约）                 │
│   ├── 保证期开始追踪（默认90天）                                   │
│   ├── 薪资谈判 → 候选人授权薪资脱敏上链                            │
│   └── 猎头TrustScore获得成单加分                                   │
│           ↓                                                         │
│   第五步：保证期验证与分账触发                                      │
│   ├── 保证期内追踪候选人在职状态                                   │
│   ├── 保证期结束（90天）→ 触发分账合约                             │
│   ├── 智能合约自动分账（猎头70%/候选人15%/平台15%）                │
│   └── HR强制评价（能力匹配度/猎头跟进质量/专业度）                 │
│           ↓                                                         │
│   第六步：信任回流与信用升值                                        │
│   ├── 猎头TrustScore更新（链上不可篡改）                           │
│   ├── 候选人信用评分更新（动态升值）                               │
│   ├── 企业背书添加到候选人链上时间线                               │
│   └── 信任流转完成 → 推荐质量提升 → 更多高质量候选人愿意参与       │
│           ↓                                                         │
│   【飞轮闭环】：回到第一步，形成正向自驱循环                       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**飞轮关键指标**：

| 指标 | 定义 | 作用 |
|------|------|------|
| **推荐成功率** | 入职数 / 推荐总数 | 衡量猎头推荐质量 |
| **链上成单率** | 链上存证的成单数 / 总成单数 | 衡量信任流转覆盖率 |
| **TrustScore均值** | 所有猎头的TrustScore平均值 | 衡量平台整体信任水平 |
| **候选人信用均值** | 所有候选人的信用评分平均值 | 衡量候选人池质量 |

## 4.4 综合匹配度算法公式（从v1.4补入）

> **核心理念**：候选人与职位的匹配不是简单的关键词匹配，而是多维度的综合匹配度计算。

### 公式定义

```
综合匹配度 = JD契合度 × 0.4 + 圈层相似度 × 0.25 + TrustScore权重 × 0.20 + 关系权重 × 0.15

取值范围：0-100分
推荐阈值：≥60分 → 系统自动推送给猎头
优质阈值：≥80分 → 系统优先推荐给高TrustScore猎头
```

### 各维度详细计算

#### 1. JD契合度（权重40%）

**计算方式**：基于LLM语义理解，对比JD需求与候选人简历

```
JD契合度 = (技能匹配度 × 0.3 + 经验匹配度 × 0.3 + 薪资匹配度 × 0.2 + 行业匹配度 × 0.2)

其中：
- 技能匹配度：JD关键词与候选人能力标签的语义匹配（AI解析）
- 经验匹配度：JD年限要求与候选人工作年限对比
- 薪资匹配度：JD薪资范围与候选人期望薪资匹配度
- 行业匹配度：JD行业与候选人行业背景匹配度

取值范围：0-100分
```

#### 2. 圈层相似度（权重25%）

**计算方式**：基于社交图谱分析，计算候选人与目标企业圈层重叠度

```
圈层相似度 = Σ(圈层权重 × 圈层重叠度)

其中：
- 大厂圈层权重：1.0（腾讯/字节/阿里/美团/拼多多）
- 行业圈层权重：0.7（互联网/金融/医疗/教育）
- 校友圈层权重：0.5（985/211/海外名校）

圈层重叠度 = 候选人圈层与目标企业圈层重叠的人数 / 候选人总圈层人数

取值范围：0-100分
```

#### 3. TrustScore权重（权重20%）

**计算方式**：推荐猎头的TrustScore高低影响匹配可信度

```
TrustScore权重 = 推荐猎头TrustScore / 100

取值范围：0-100分（猎头TrustScore为0-100）

说明：高TrustScore猎头推荐的候选人，匹配可信度更高
```

#### 4. 关系权重（权重15%）

**计算方式**：推荐猎头与候选人的关系亲疏影响推荐可信度

```
关系权重 = 关系类型权重 × 关系强度

其中：
- 一度人脉（直接朋友）：权重 1.0
- 二度人脉（朋友的朋友）：权重 0.7
- 三度人脉（陌生人）：权重 0.3

关系强度 = 猎头对候选人的熟悉程度评分（1-5星）× 0.2

取值范围：0-100分
```

### 匹配度应用场景

| 场景 | 应用方式 |
|------|----------|
| **猎头HC推荐** | 系统筛选匹配度≥60的候选人，推送给猎头 |
| **候选人职位推荐** | 系统筛选匹配度≥60的职位，推送给候选人 |
| **优先推荐** | 匹配度≥80的候选人，优先推送给高TrustScore猎头 |
| **匹配排序** | 按匹配度降序排列候选人列表，猎头从高匹配度开始推荐 |
