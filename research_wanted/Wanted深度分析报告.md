## 二、三大角色交互流程

### 1. 求职者端 (Candidate)

```
注册 → 职位搜索 → 申请 → 面试 → 薪资 → 入职
 ↓       ↓        ↓       ↓       ↓
OneID   wdlist   状态追踪  AI辅导  薪酬数据
       (标签筛选)         面试提案  概率计算
```

**核心功能：**
- **Career Connect** - 可视化职业时间线 + 排名百分比
- **AI 面试辅导** - 基于 JD 生成问题+反馈
- **薪酬概率计算器** - 输入职位/经验，显示薪资排名
- **面试提案系统** - 企业主动发起邀请（反向匹配）

### 2. 企业端 (Employer)

```
注册认证 → 发布职位 → 筛选候选人 → 面试协调 → 录用结算
   ↓         ↓           ↓           ↓         ↓
电子签约   24h 审核    AI 人才池    日程系统    7%佣金
免费摄影   外链分享   推荐引擎    自动提醒
```

**核心功能：**
- **人才池探索** - AI 推荐候选人，平均 3 天接受面试
- **面试日程系统** - 最多 5 个时间选项，提前 1 天自动提醒
- **Pay-on-Hire** - 录用成功才收费 7%年薪
- **权限分层** - 管理员/审核员角色分离

### 3. 推荐人端 (Referrer) ⭐核心创新

```
推荐人 → 分享职位 → 候选人申请 → 企业录用 → 奖励发放
  ↓                              ↓              ↓
认证                        跟踪链          50-200 万韩元
```

**三方关系模型：**
```
推荐人 ────推荐────→ 候选人
  │                    │
  │                    ↓
  │               企业录用
  │                    │
  ↓                    ↓
奖励 ←───支付─────────┘
```

**激励机制：**
- 奖励约 50-200 万韩元（成功入职后）
- 信任评分体系（推荐成功率→排名）
- 高信任推荐人→优先曝光优质职位

## 七、Wanted 核心功能详解

### 7.1 AI 概率预测系统

Wanted 的 AI 概率预测是其差异化竞争力之一，基于 1000 万匹配数据训练：

**面试成功率预测**：
- 输入：候选人背景 + JD 要求
- 输出：面试成功率百分比（如 78%）
- 价值：帮助候选人筛选高成功率岗位，减少无效投递

**薪酬匹配度预测**：
- 输入：候选人期望薪资 + 市场薪资分布
- 输出：薪酬匹配度百分比（如 85%）
- 价值：帮助候选人评估薪资合理性，提前规划谈薪策略

**对人人猎的启示**：
- 可应用于 HC 端：为推荐者展示每个 HC 的面试成功率、薪酬匹配度
- 可应用于候选人端：为候选人推荐高成功率岗位
- 数据来源：初期可使用公开数据+平台数据训练模型

### 7.2 标签式职位发现

Wanted 的职位发现页面采用视觉标签卡片设计：

**设计特点**：
- 标签快捷筛选（职能/城市/薪资/企业类型）
- 点击即过滤，无需刷新页面
- 视觉层级清晰，浏览效率高

**对人人猎的启示**：
- 替代传统下拉筛选框
- 提升移动端浏览体验
- 降低推荐者筛选 HC 的认知负担

### 7.3 面试提案系统（反向匹配）

Wanted 的"면접 제안（面试提案）"是其核心创新之一：

**流程**：
```
企业发现候选人 → 发起面试提案 → 填写时间选项 + 岗位亮点 → 候选人接受 → 面试日程同步
```

**关键设计**：
- 企业可提供最多 5 个面试时间选项
- AI 自动生成个性化岗位亮点（基于候选人背景）
- 候选人一键接受，日程自动同步

**对人人猎的启示**：
- 推荐者上传候选人后，系统自动匹配其他 HC
- 企业 HR 可主动发起面试提案
- 提升候选人体验（被动等待→主动邀请）

### 7.4 推荐人（Referrer）系统

Wanted 的推荐人系统是其核心创新，值得深入借鉴：

**三方关系**：
```
推荐人 ─推荐→ 候选人 ─入职→ 企业
  ↓                              ↓
奖励 ←────支付─────────────────┘
```

**关键设计**：
- **零门槛**：推荐人无需认证，注册即可开始推荐
- **一键分享**：生成分享链接，通过微信/脉脉分享
- **实时追踪**：推荐人可查看候选人进度（已查看/已申请/面试中/已录用）
- **自动奖励**：候选人入职后，平台自动发放奖励
- **信任评分**：推荐成功率→排名→曝光权重

**激励机制**：
- 奖励金额：约 50-200 万韩元（约 3000-12000 人民币）
- 高信任推荐人：优先推送优质职位 + 奖励加成

**对人人猎的启示**：
- 引入"推荐人"角色，扩大候选人来源
- 轻量化参与，降低门槛
- 信任评分体系，激励高质量推荐

### 7.5 职业时间线（Career Connect）

Wanted 的 Career Connect 功能为用户提供职业成长轨迹可视化：

**功能内容**：
- 工作经历时间线
- 技能成长轨迹
- 薪资增长曲线
- 排名百分比（在同类人才中的位置）

**对人人猎的启示**：
- 为推荐者建立"职业时间线"：成单记录、收入增长、技能认证、社区贡献
- 替代静态简历，展示动态成长
- 提升推荐者的成就感和归属感

### 7.6 信任评分体系

Wanted 的信任评分体系是其推荐人系统的核心机制：

**评分维度**：
- 推荐成功率（成功入职数 / 总推荐数）
- 候选人质量（HR 评分）
- 响应速度
- 候选人留存（在职时长）

**评分等级**：
- 新手推荐人（0-2.0）
- 活跃推荐人（2.1-3.5）
- 优质推荐人（3.6-4.5）
- 资深推荐人（4.6-5.0）

**权益差异**：
- 高评分推荐人：优先推送优质职位 + 奖励加成 + 专属客服

**对人人猎的启示**：
- 建立推荐者信任评分体系
- 建立推荐人信任评分体系
- 评分→排名→曝光权重的飞轮机制

## 八、技术实现建议

### 8.1 AI 概率预测系统

**技术选型**：
- 模型：LLM（如 GPT-4、Claude）+ 微调
- 数据源：平台历史成单数据 + 公开薪资数据
- 特征工程：候选人背景、JD 要求、市场薪资分布、历史成功率

**实现步骤**：
1. 数据收集与清洗（脱敏处理）
2. 特征工程与模型训练
3. API 接口开发
4. 前端可视化展示

### 8.2 推荐人系统

**技术选型**：
- 推荐关系绑定：短链 + Cookie + 用户 ID
- 实时追踪：WebSocket 推送
- 奖励发放：定时任务 + 银行转账 API

**实现步骤**：
1. 推荐链接生成与追踪
2. 推荐关系绑定（候选人注册时记录推荐人 ID）
3. 进度追踪与通知
4. 奖励计算与发放
